01 / THE PROBLEM

A package contains a lot of text.
Which part is the name?

Product labels mix brand names, descriptions, dosage, nutrition facts, and promotional copy. A text recognizer can return all of it. This project studies a more focused first step: locating a contiguous product-name or brand region so a reading system can work with a smaller crop.

The trained detector has one class, product_name. It predicts a location and score, not a text transcription. A brand-only crop may still be insufficient to identify a particular product variant.

What you will learn

How to annotate name regions, fine-tune and evaluate a detector, interpret its tradeoffs, and correctly decode its exported tensors for Android.

Research foundations

The original YOLO paper by Redmon et al. (2016) describes a unified detector that predicts boxes and class probabilities from an image. That provides historical context; this project uses the modern Ultralytics implementation, rather than reproducing the original paper’s architecture. [1]

Ultralytics detection documentation explains bounding-box outputs and the train, validate, predict, and export workflow. [2] For the reading stage, Google ML Kit Text Recognition v2 is a possible Android OCR component. It is included here as a reference, not a claim that the app uses it. [3]

Other ways to locate and read text

CRAFT predicts character regions and their connections to locate scene text. It offers a text-focused alternative to a detector trained on product-name regions; selecting which text identifies the product would remain a separate step. [4]

Shi, Bai, and Yao combine learned image features, sequence modeling, and transcription. Their research addresses reading a text image, a different task from locating its region in a full photograph. [5]

Microsoft’s 2017 Seeing AI announcement illustrates barcode-based product identification alongside short-text reading. A barcode route depends on a readable code and product lookup; direct OCR depends on visible identifying text. The preferable approach depends on the available visual information and product data. [6]

Why use a detector before OCR?

A targeted crop can reduce unrelated text entering the reading stage. But a missed or clipped name region removes information OCR needs. Compare this approach with full-image OCR on the same photographs before claiming that it improves reading accuracy.

Annotation format

Each image has a matching text label file. Each line contains a class ID and normalized box coordinates:

class_id center_x center_y width height
0        0.50     0.40     0.30  0.12

The numbers above are illustrative. Divide horizontal coordinates by image width and vertical coordinates by image height. Class 0 represents product_name. Draw a tight box around the contiguous identifying text, rather than the entire package.

02

Fine-tune the supplied checkpoint

The selected run used a Tesla T4, a 640-pixel input, AdamW, and a low learning rate. The saved configuration allowed up to 70 epochs with patience 20. The starting checkpoint was supplied from the earlier project training.

from ultralytics import YOLO

model = YOLO("provided_final640.pt")
model.train(
    data="real_data.yaml", imgsz=640,
    epochs=70, patience=20, batch=8,
    optimizer="AdamW", lr0=0.00015,
    lrf=0.1, weight_decay=0.0005,
    seed=663, device=0,
    fliplr=0.0, flipud=0.0, mosaic=0.0,
    project="results", name="label_finetune"
)

This is a compact training example, not the complete reproducibility configuration. Download the recorded training arguments for the full run settings. Mirrored text and mosaic were avoided in the study.

03

Validate, select, then test

Compare candidates on validation data. Select the checkpoint, resolution, and confidence threshold there before reporting test results. This project’s selected threshold was 0.075 with NMS IoU 0.6, favoring recall for OCR crop proposals.

model = YOLO("selected_best.pt")
metrics = model.val(data="real_data.yaml", split="test", imgsz=640)
print("mAP50:", metrics.box.map50)
print("mAP50–95:", metrics.box.map)

results = model.predict(
    "example.jpg", imgsz=640, conf=0.075,
    iou=0.6, max_det=100, save=True, save_crop=True
)

Standard validator precision and recall can use a different curve operating point from the app’s fixed threshold. Label these results separately.

04

Export the model

The recorded export used Ultralytics 8.4.171 and produced a float32 TFLite model of about 12.3 MB. Package versions and export routes can change tensor layouts; inspect the actual model.

from ultralytics import YOLO

best_model = YOLO("selected_best.pt")
tflite_path = best_model.export(format="tflite", imgsz=640)
print(tflite_path)

05

Decode correctly on Android

INPUT · FLOAT32[1, 3, 640, 640]

NCHW: red plane, green plane, blue plane.

OUTPUT · FLOAT32[1, 5, 8400]

Center x, center y, width, height, name score.

  1. Orient the photo. Resize with preserved aspect ratio and letterbox to 640 × 640 using RGB padding 114.
  2. Normalize RGB values by 255 and fill a native-order float buffer in planar channel order.
  3. Read channel c, candidate i at c * 8400 + i. Multiply normalized box coordinates by 640 and convert centers to corners.
  4. Filter scores and apply external non-maximum suppression (NMS). There is no extra objectness channel or sigmoid step.
  5. Subtract letterbox padding, divide by resize scale, and clip to the original image. Crop before OCR.

Place best.tflite and labels.txt in app/src/main/assets/. The alternate export in the workspace uses a different contract; do not combine its decoder with this model.

How to read these metrics

Intersection over union (IoU) measures overlap between a predicted box and an annotated box. mAP50 uses IoU 0.50; mAP50–95 averages AP over thresholds from 0.50 to 0.95. With one class, mAP reflects that class’s localization and ranking. Precision asks how many predicted detections were correct; recall asks how many annotated regions were found. None of these tells us whether OCR read the text correctly.

Limits of the evidence

No statistical significance was established. The new phone test set covers only three product groups. Original test examples appeared in earlier notebook outputs, and training-time provenance of the supplied checkpoint cannot be independently reconstructed. Annotation policies vary, stock-image provenance is incomplete, and only one empty-label test image is present. These results do not establish broad generalization.

Export verification compared raw outputs with PyTorch on six validation images. The maximum coordinate difference was 0.00160217 pixels and maximum score difference 0.00000256. That supports conversion numerics; it does not substitute for full exported-model accuracy or target-phone latency testing.

07 / NEXT STEPS

Better evidence.
Better reading.

The central lesson is to evaluate the complete chain. A detector can improve box localization while the reading experience stays unchanged—or worsens. Preserve both checkpoints until the app’s downstream performance determines which is better.

  • Collect new physical packages and independent capture sessions, including negative scenes.
  • Make the annotation policy consistent and add human OCR transcripts.
  • Measure exported-model accuracy, actual phone latency, and camera-coordinate correctness.
  • Compare detector-assisted OCR against full-image OCR using exact product-name correctness.
